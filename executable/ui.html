Documentation & Guides

The unified automation pipeline natively connects your official master schedule with registrar student lists to concurrently build 3 complete document packages:

  • 1. Attendance Sheets (.docx): Individual monthly documents (e.g., Aug–Dec or Jan–May) customized with your exact scheduled weekdays and dates.
  • 2. CEIT Department Forms (.docx): 7 standardized forms including Course Syllabus Acceptance Form, Midterm & Finals Exam Returns, Midterm & Finals Table of Specifications (TOS) Acknowledgments, and Midterm & Finals Grade Discussion Forms.
  • 3. Official CvSU Grade Sheets (.xlsx): Native workbooks using official Lecture or Lecture & Lab templates with student records and signature metadata while preserving all formula calculations.
All documents are generated in a single click, completely eliminating repetitive manual data entry.

1. Instructor Master Schedule (.xls / .xlsx):

Upload your raw Excel schedule file. The parser traces your name, college header, academic year, semester, and individual class blocks (Course/Section, Schedule Code, Subject Code & Description, Time/Days, and Room). Any blocks designated as Async or Asynch are automatically omitted to target only in-person sessions.

2. Student Rosters (.xlsx / .xls / .csv):

Student lists must be downloaded directly from registrar.cvsu.edu.ph.

⚠️ Critical Roster Column Requirement: Rosters must contain strictly Name and Student number columns only. If files contain more than these two headers (e.g., Email, Course, Remarks, Status), the parser will produce an error.

Files must be saved using the standard university naming format:

{Course/Sec} List of Students for {ScheduleCode}-{Subject}.xlsx Example: BSCS1-4 List of Students for 202612040-DCIT 21A - INTRODUCTION TO COMPUTING.xlsx

When schedule and roster files are loaded, the Detected Classes & Subject Types panel will appear with all identified subjects:
  • Lecture and Lab: Uses GRADING_LECTURE_LAB_TEMPLATE.xlsx. Populates Lecture, Laboratory, Consolidated, and Grading Sheet tabs. Automatically selected if schedule entries list laboratory hours or rooms.
  • Lecture only: Uses GRADING_LECTURE_TEMPLATE.xlsx. Populates Lecture and Grading Sheet tabs.
You can manually switch any class using its dropdown. Your selections are automatically remembered in your local browser storage.

Use the Start Date and End Date pickers to constrain the exact active calendar range for attendance sheets:
  • When set: Only dates matching your scheduled weekdays falling strictly between the Start Date and End Date will receive attendance columns.
  • When omitted: The generator defaults to standard semester months (August–December for 1st Semester, January–May for 2nd Semester).
Note: Both Start and End dates must be provided together, with Start Date preceding End Date.

Dynamic College Header: Automatically applies the detected College title to Grade Sheets (cell A9) and document headers.
File Lock Resilience: Files are written using atomic replacements. You can safely keep reference rosters open in Excel during generation.
Diagnostics: Detailed execution logs are stored at %APPDATA%/CVSU_Generators/logs/generator.log.
