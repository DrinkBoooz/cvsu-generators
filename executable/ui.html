Documentation & Guides

Instead of manually typing class details via the CLI, the unified script automatically constructs the required metadata by pairing the official raw .xls schedule format alongside standardized student lists.

When executed, it natively parses your schedule, extracts your name and academic semester, and simultaneously traces the exact Class, Room, Times, and Day placements by analyzing block offsets. Generated .docx outputs are perfectly scoped and organized within nested categorical directories to eliminate clutter.

Schedule Parsing: The system crawls the natively formatted Excel 97-2003 schedule blocks. Completely filters out blocks mapped as "Async" or "Asynch".

Student Roster Extraction: The generic schema relies heavily on filename formatting to dynamically bind to your schedule blocks. Student lists MUST exist using the precise format:

{Course/Sec} List of Students for {ScheduleCode}-{Subject}.xlsx
Example: BSCS1-4 List of Students for 202612040-DCIT 21A...xlsx
Origin Requirement: Rosters MUST be manually exported from registrar.cvsu.edu.ph. The file must strictly contain exactly Student Name and Student Number columns.
