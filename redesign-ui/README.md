# CvSU Gen — Design Research Outputs

This bundle turns the supplied UI handover, uploaded `frontend-design.SKILL.md`, Apple HIG, and the two anti-generic UI repositories into an actionable project design contract.

## Files

- `CvSU_Gen_DESIGN.md` — proposed design constitution and durable design-system/interaction contract.
- `CvSU_Gen_AI_UI_Review_Checklist.md` — acceptance checklist for generated or revised UI.
- `CvSU_Gen_Agent_UI_Instructions.md` — copy-ready instructions for an AI coding agent.
- `CvSU_Gen_Design_Research_Notes.md` — research synthesis, source links, tensions, and project-specific decisions.
- `cvsu-gen-ui-tokens.css` — provisional semantic CSS tokens for light/dark exploration; not official CvSU brand colors.

## Important status

These are review outputs only. They have not been added to or committed into the application repository. They do not authorize production implementation. The provisional green palette must be checked against the actual CvSU/CEIT logo and repository assets before production use.

## Recommended use

1. Review `CvSU_Gen_DESIGN.md` as the design authority for future UI work.
2. Use the agent instructions when asking an AI coding agent to explore or implement UI.
3. Use the checklist for every screenshot/prototype/PR review.
4. Keep these files outside the application repository until you explicitly approve adding them and the correct location is verified under repository governance.
